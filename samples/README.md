# Sample images (synthetic)

These images are **synthetic and procedurally generated** by `defectml.data.synthetic` (seeded, so they can be reproduced exactly with `python -m app.cli bootstrap-demo`). They are **not** photographs of real products, and you should not read results on them as evidence of real-world accuracy.

They are included so that you can:

* try the Inspect, Batch and Review pages right after installation, and
* run the Playwright end-to-end tests (`frontend/e2e/`) without downloading any third-party dataset.

| Folder | Product key | Contents |
|---|---|---|
| `demo-pcb/` | `demo-pcb` | 3 normal boards and 4 with defects (missing component, contamination, solder bridge) |
| `demo-metal/` | `demo-metal` | 2 normal washers and 3 with defects (scratch, dent, contamination) |

The file name gives the ground truth, for example `A_0162_defect-contamination.png`. All files come from the **held-out test split** of each demo dataset, so no model has seen them during training or threshold selection.
